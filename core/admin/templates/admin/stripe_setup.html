Local development

Stripe won't accept a localhost webhook URL. Stripe pings the URL during creation; localhost / 127.0.0.1 fail reachability. For local testing, use the Stripe CLI instead — it tunnels real Stripe events to your machine without ever registering a server-side endpoint: 
stripe listen --forward-to http://localhost:8000{{ stripe_listen_path }}
Copy the whsec_… the CLI prints into .env as STRIPE_WEBHOOK_SECRET and restart — done.

When you deploy to a public host, come back to this page from there and the Create button will work.
